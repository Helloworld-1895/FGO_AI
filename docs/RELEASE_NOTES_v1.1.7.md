# FGO AI v1.1.7

发布日期：2026-11-12

## 主线自动编成接续修复

- 主线推进已处于“自动编成执行确认”、简版确认弹窗或编队“决定”页面时，可以直接继续；停止后重新开启也可接续，无需先记录开战失败。
- 从编队页面主动进入自动编成仍要求实际开战失败授权；只有点击成功才更新确认/决定状态。
- 本次修复仅针对主线自动编成，不改变自由关卡与无限刷的模式行为，也不改变 CPU/CUDA 包的默认配置。
- 已同步 Word 操作指南的版本、目录示例与第 7.2 节。

## 战败续关修复

- 修复部分实时战败布局已识别但执行续关时被拒绝的问题；执行前仍检查已启用模板的正常阈值与资源授权，不扩大资源额度。
- 已尝试授权资源但按钮未能安全定位或执行时，暂停原因会明确说明执行失败。
- 已同步操作指南第 9.3 节。

## 下载与更新

按硬件选择 CPU 或 CUDA ZIP，并核对同名 SHA-256 校验文件。CUDA 包需要兼容的 NVIDIA 显卡与驱动，首次启动先运行 GPU 自检，详见 [GPU 配置](GPU_SETUP.md)。

ZIP 只含一个 FGO_AI-v1.1.7-Windows-CPU/（或 CUDA）总文件夹，内含 Word 操作指南和 FGO_AI/ 软件文件夹。先阅读指南，再进入软件文件夹启动。软件内 docs/ 保留同一指南。

升级前备份配置，完整解压到新目录，按操作指南迁移所需设置；不要混用 CPU/CUDA 或覆盖旧版 app。首次运行、切换模式或修改配置后短时试跑并人工看护。
