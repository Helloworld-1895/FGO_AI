# FGO AI v1.1.16

- 修复指令卡恢复时丢弃完整 AI 选卡方案：三个位置全空时按当前截图重新规划三张；只在确认已选一两张时补足剩余位置，并保留已选顺序。
- 点击后画面无进展时重新识别前景并尝试其他操作，覆盖主线、自由关卡、无限刷、幕间物语与 ORT；识别到登录奖励先关闭弹窗，再读取后面的关卡。持续无法恢复时保存截图并提示人工处理。
- 关闭“后台知识提炼”后，正常、精简、本地 4B/9B 特调及其 Pro 组合都不再向模型发送笔记，也不发起笔记总结或整本压缩；本地笔记保留，Pro 工作历史及其压缩照常。
- Windows 项目内 Ollama 下次启动时默认关闭主机提示缓存（`LLAMA_ARG_CACHE_RAM=0`），减少连续识图时的内存增长；当前槽位与 KV 缓存不受影响，其他本地模型设置不变。
- 云端接口按服务商和模型发送受支持的思考参数：硅基流动 Qwen、DashScope Qwen、DeepSeek、Claude Messages、智谱 GLM、MiniMax 与 OpenAI 等；新建接口默认关闭思考，已有档案保留原设置；GLM-5.3-Flash 等必须思考的模型使用最低档，未知接口保留服务端默认。
- 输出预算调整：关闭思考时单次最多 49152 个输出 Token，开启或可能思考时 65536；启动探测确认不思考时给 4096，仍可能思考时给 24576，为正文留出空间。
- 本地模型与云端配置隔离：保存本地 Ollama 设置不再切换当前接口；云端档案与本地档案重名时，本地档案保留为“（本地）”，避免被覆盖。
- 主线助战 AI 返回有效选行时，缺少或误填 `confidence` 仍会执行；提示词明确从者等级只读每行头像上沿（有斜线取左侧），玩家名一栏紧邻“最后登录”的等级是御主等级，不能用于筛选或填写从者等级。
- 修正宝具测试读取展开字典的字段位置，补充指令卡恢复与运行时效率的回归测试。

操作指南已同步更新。升级前请备份设置。本版同时提供 Windows CPU、Windows CUDA 与 macOS arm64 三个包。
