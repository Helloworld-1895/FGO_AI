## 下载与更新

按硬件选择 CPU 或 CUDA ZIP，并核对同名 SHA-256 校验文件。CUDA 包需要兼容的 NVIDIA 显卡与驱动，先运行 GPU 自检，详见 [GPU 配置](GPU_SETUP.md)。CPU/CUDA 默认配置保持现有设置。

ZIP 内只有一个总文件夹，内含 Word 操作指南与 FGO_AI/ 软件文件夹；软件 docs/ 保留字节一致的指南。升级前备份配置，完整解压到新目录，避免覆盖旧 app 或混用两个包。首次运行后短时试跑并人工看护。
