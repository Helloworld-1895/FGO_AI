# FGO AI v1.1.17

- 首次提供 Android 正式签名包 `FGO_AI-v1.1.17-Android-release.apk`（Android 8.0+、arm64-v8a、Shizuku）。正式包固定使用远程 AI 接口，不启用本地 GGUF 离线推理：模型页只显示说明，本地服务拒绝启动，启动时会把旧的 `local_ai_enabled` 关闭并把指向 `127.0.0.1:11436` 的接口档案停用后切回远程档案。debug 开发包与桌面版本地模型能力不变。
- Android 正式包与调试包使用不同签名：从旧 debug 安装升级需先卸载一次，之后同密钥的正式版本可覆盖升级；安装包随 Release 提供 SHA-256。
- 幕间物语专清修复：混合列表改为逐行筛选并优先选择可挑战幕间卡（不误点强化/进阶或已锁定/已完成条目），无快速跳转按钮的节点卡改为点击任务标题框中心；当节点无可挑战幕间时，按左上角真实按钮位置优先点击「前往幕间物语」（兼容 OCR 拆词与宽框）而非点「关闭」退出地图。
- 幕间物语回退改进：交给 AI 决策时补充「前往幕间物语」与「关闭」的使用条件；尚未进入幕间列表时的 `invalid_start` 交回主循环处理而非直接终端暂停。
- Windows CPU、Windows CUDA 与 macOS arm64 三个桌面包与 Android 包使用同一份根目录 `VERSION`；操作指南已同步封面版本、日期和 Android 正式包限制说明。

升级前请备份设置。Android 正式包首次安装前，请确认已安装并授权 Shizuku。
