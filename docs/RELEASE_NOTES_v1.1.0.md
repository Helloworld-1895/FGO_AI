# FGO AI v1.1.0

## 自由关卡清除

- 发布当前版本的自由关卡探索与首次清除流程，支持起点章节选择、地图节点扫描、详情列表识别，以及战斗结算后的探索接管。
- 根据完成状态、剩余次数和可挑战条件选择目标，跳过已清除、未解锁和非目标条目。
- 主线推进、自由关卡与无限刷保持各自模式边界；自由关卡开启时优先于无限刷。
- 新增 [自由关卡使用说明](FREE_QUEST.md)，特别说明：勾选开关和选择起点后，必须点击“保存任务与自由关卡设置”，再启动或重启自动化。

## 发布包

- 同时发布 Windows CPU 和 CUDA 两个独立编译包，版本号统一为 `1.1.0`。
- 随包提供使用文档、版本文件和许可证说明；正常运行不需要安装 Python。
- 保留启动器的本地校验与下载修复流程，提供 ZIP 的 SHA-256 校验文件。
- 包含当前源码中的日志容量管理与模型请求复用优化。

## CUDA 说明

CPU 包使用 CPU OpenCV；安装 NVIDIA 显卡或系统 CUDA 不会把这一包自动转换为 CUDA 版本。CUDA 包随附模板匹配依赖，不需预装 Python、Conda 或 CUDA Toolkit，但仍需兼容的 NVIDIA GPU 和驱动。两个包首次运行均默认 CPU；CUDA 用户应先运行 `启动FGO_AI.bat --self-test-cuda`，再在 GUI 选择 GPU/混合匹配，保存并重启自动化。完整边界见 [GPU 配置](GPU_SETUP.md)。

## 使用边界

推荐 `1600x900` MuMu/ADB 环境。自由关卡依赖账号已解锁的章节、画面识别以及可用的战斗队伍，不保证活动地图、特殊 Boss 或所有账号状态都能自动完成。升级请先关闭旧程序，解压到新目录；如迁移 `app/profiles/user.yaml`，请检查模式、队伍、设备和模型设置后再运行。
