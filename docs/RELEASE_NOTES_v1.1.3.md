# FGO AI v1.1.3

## 更新内容

- 新增“启用 AI 接口”总开关，关闭后自动化、后台总结和助手对话均不再发起新的 AI 请求；排队和压缩后的请求也会重新检查开关。设置立即保存；若本轮启动时 AI 已关闭，重新开启后请重启自动化以加载模型。
- 改善未配置模型或关闭 AI 时的本地恢复：优先使用可确认的本地操作，无法处理的画面给出明确的人工暂停原因。
- 修复战斗动画被误判为可选宝具卡页、AI 建议在旧截图上等待，以及自由关卡遗留交接状态引发的异常暂停。
- 保持主线、自由关卡与无限刷模式隔离。

## 升级

关闭旧版本，将 CPU 或 CUDA 安装包完整解压到新目录，再启动程序。CUDA 包需要兼容的 NVIDIA 显卡与驱动；不确定时选择 CPU 包。AI 总开关详见 [模型顾问配置](AI_SETUP.md)。
