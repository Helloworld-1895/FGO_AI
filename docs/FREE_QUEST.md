# 自由关卡清除（v1.1.0）

自由关卡模式用于探索已经解锁的章节，寻找尚未完成首次清除的自由关卡。程序先处理主线记录和章节地图，再识别节点、关卡详情及列表，交给现有助战、编队、战斗和结算流程执行。目标是完成首次清除，不是反复刷取已经清除的同一关。

## 开始前

- Windows 10/11 x64，MuMu/ADB 连接正常，游戏画面为 `1600x900`。
- 账号已经解锁目标章节，队伍、技能、宝具、指令卡及助战设置适合待挑战关卡。
- 建议先在熟悉的低难度章节观察一轮，确认识别、进本、战斗和结算流程。首次使用不建议无人值守。
- 如需模型处理助战或未知画面，先完成 [AI 配置](AI_SETUP.md)。“大模型辅助”开关不会自动提供模型、API key 或调用额度。

## 开启与保存

1. 打开控制面板，连接模拟器。
2. 在任务设置区域勾选 **“自由关卡开关”**。
3. 在 **“起点”** 选择要开始扫描的章节。章节列表覆盖第 1 部、第 1.5 部及第 2 部已实现的章节；实际可进入范围取决于账号解锁情况和画面识别。
4. 按需设置“大模型辅助”和“非目标地图退出找目标”。配置队伍与战斗策略，并检查体力补充及各类苹果额度。
5. 点击 **“保存任务与自由关卡设置”**。
6. 若自动化已经运行，先停止，再重新启动，让本次运行读取保存后的配置。

**只勾选开关或选择章节，不点击保存，运行时仍会使用旧配置。** 编译包的用户配置文件是 `app/profiles/user.yaml`，不是包根目录的 `profiles/user.yaml`。

启动按钮和日志可能继续显示“自动推进主线”等通用文案。应以保存文件中的 `free_quest.enabled`、`start_chapter`，以及运行日志中的 `explorer`、`tap_main_record` 等记录判断实际模式。

## 如何清除关卡

- **章节导航**：根据起点和章节顺序寻找目标章节，从主界面或主线记录进入地图；已有地图或详情页会尝试直接接管。
- **地图探索**：结合模板、OCR 与地图视口移动识别候选节点，按地图范围逐步扫描。红点只是候选提示，并不等于一定存在未清除自由关卡。
- **详情与列表**：读取关卡名称、剩余次数、完成状态、首通奖励等证据，选择可挑战且未完成首次清除的条目。已清除、未解锁或非目标条目跳过；列表按需继续滚动检查。
- **战斗与结算**：助战、编队、战斗使用当前已配置策略，结算后继续自由关卡探索。需要多次挑战才能完成首通的关卡，会依据详情重新判断。
- **换章**：当前地图扫描完成或确认没有目标后，尝试返回章节列表继续探索。识别不确定、加载、受限编队或特殊界面会走对应守卫与恢复流程，可能需要人工处理。

不承诺所有章节、活动地图、特殊剧情、特殊 Boss 或账号状态都能自动通过。未解锁章节不会被此模式自动解锁；战斗能否获胜取决于队伍和策略。

## 与主线、无限刷的关系

| 模式 | 用途 | 开启方式 |
| --- | --- | --- |
| 主线推进 | 沿当前主线继续操作 | 关闭自由关卡和无限刷后保存 |
| 自由关卡 | 按章节寻找未完成首次清除的条目 | 开启自由关卡，选择起点并保存 |
| 无限刷 | 反复进入已配置的同一关卡 | 关闭自由关卡，准备入口模板，开启无限刷并保存 |

主线状态机与自由关卡探索严格隔离；自由关卡开启时，无限刷路径不会生效。为方便确认模式，建议只保留要使用的开关。切换模式后保存并重启自动化。

## 配置示例

推荐通过 GUI 保存。手动编辑时，先关闭程序，将以下字段合并到 `app/profiles/user.yaml` 的现有同名节点，不要用此片段覆盖整个文件：

```yaml
free_quest:
  enabled: true
  start_chapter: fuyuki
  model_assist: false
  non_target_retreat: true
  explorer:
    enabled: true
infinite_farm:
  enabled: false
```

`fuyuki` 表示冬木；其他章节建议直接在 GUI 下拉框选择。`model_assist` 为自由关卡探索的可选辅助，战斗和助战所需的模型设置仍独立生效。默认发布配置关闭自由关卡，避免用户首次启动时直接开始清图。

## 故障排查

- **开关已勾选但不清图**：先核对是否点击保存、`app/profiles/user.yaml` 修改时间是否更新、`free_quest.enabled` 是否为 `true`，然后重启自动化。
- **一直进入同一关**：确认当前不是无限刷，查看详情中是否还剩首通次数；不要把地图红点直接当成未清除状态。
- **地图上找不到节点或详情识别错位**：恢复 `1600x900`，关闭遮挡弹窗，确认处于已解锁章节；检查画面和 explorer 阶段后人工返回地图重试。
- **停在助战或编队**：检查助战筛选、模型连接和可用队伍；数据丢失、受限编队及特殊 Boss 不属于普通自由关卡流程。
- **体力耗尽**：检查是否启用体力补充以及苹果额度；不要期待自由关卡开关自动授权使用所有资源。
- **准备反馈**：提供版本、章节、当前界面、保存后的模式字段和脱敏日志片段，移除 API key、账号信息及设备序列号。
