# FGO AI v1.1.15

- 本地 Ollama 改为原生 `/api/chat` 视觉接口，不再套用 OpenAI 兼容层；生产提示词的上下文上限提高到 32768，长提示词包不会被本地模型拒绝。
- 新增“本地视觉模型”选择：9B 主力（`qwen35-9b:latest`）与 4B 快速档（`qwen3.5:4b-q4_K_M`），默认 9B。
- 新增“运行方式”：GPU 全量加载、混合部分卸载、CPU 纯计算；搭配“保存本地模型设置”立即写入配置。
- 新增“特调提示词”开关（默认开启），为本地模型补充逐栏读数与 JSON 输出约束，降低乱填数字和格式错误。
- 一键启动 Ollama 支持项目内自动部署：程序包使用 BITS 或 curl 断点续传，失败最多重试 4 次；模型下载中断自动重试 3 次并复用已完成部分，下载过程有进度窗口。
- 启动前检查可用内存与显存，低于建议值时提醒并给出降占用建议，但不自动修改任何开关；失败时提供“手动重试”和手动配置说明。
- 修正关闭 Skip 时带描边的剧情选项识别，避免把可选剧情卡当作普通按钮。
- 自由关卡提示词明确详情卡动作契约：详情卡只允许 `free_quest_action`，不再用普通按钮动作点“关闭”。

升级前请备份设置。本版同时提供 Windows CPU、Windows CUDA 与 macOS arm64 三个包；本地模型设置保存在配置内，旧版接口配置继续可用。
