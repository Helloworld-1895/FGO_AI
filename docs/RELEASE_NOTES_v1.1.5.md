# FGO AI v1.1.5

## 更新内容

- CPU、CUDA 发布 ZIP 都增加一个总文件夹。打开后先看到 `FGO_AI操作指南.docx` 和 `FGO_AI/` 软件文件夹；进入后者运行启动器。
- 更新 Word 操作指南的安装、目录、备份迁移和排障说明。
- 修复较矮窗口下战斗策略、助战策略保存按钮及截图页底栏被挤压的问题。
- 更新从者资料，提供从者资料库核对与补齐入口，并让该入口可在独立编译包中运行。
- 主线自动编成仅在开始战斗被拒绝后介入；清理提示词中的重复内容和未使用示例。

## 安装与更新

下载 CPU 或 CUDA ZIP 及同名 `.sha256`，核对后完整解压到新目录：

```text
FGO_AI-v1.1.5-Windows-CPU/
├─ FGO_AI操作指南.docx
└─ FGO_AI/
   ├─ 启动FGO_AI.bat
   ├─ app/
   ├─ scripts/
   └─ docs/ 等
```

CUDA 包使用对应的 `Windows-CUDA` 总文件夹。先阅读外层 Word 指南，再进入 `FGO_AI/` 启动；相对路径均以软件目录为准。更新前关闭旧程序，备份旧软件目录内的 `app/profiles/user.yaml`、`app/secrets/` 和自定义模板，再按指南迁移。请勿将新旧包互相覆盖。
