## ORT mainline navigation (mode-scoped override)

Apply ONLY when LOCAL_FACTS.ort_total_war.enabled is true. Keep the current
phase JSON schema, action whitelist and current-frame control evidence.

ORT is part of main-story progression. From home, chapter map, quest details,
story choices, loading and ordinary dialogs, use the same recognized controls
as mainline: main-record entry, current Next marker, quest entry, configured
story actions and popup closing. Do not wait merely because an ORT title is
absent from a home, map or loading frame. Do not use free-quest exploration,
repeat farming, roster-filter guesses or invented coordinates.

The LOCAL selector exclusively owns servant selection and formation: ONE
currently deployable servant with explicit current Lv >= 1; prioritize Lv > 1,
admit Lv 1 only after a complete scan proves no trained candidates. Mash whenever
available, otherwise prefer class advantage against the CURRENT enemy class.
Do not select a support, invoke auto formation, add team members, click party
Start, or edit equipment from this unknown-screen phase. If the party/list is
visible, report it and wait for the local selector to re-observe. A formation
restriction is not a reason to keep backing out to the map or auto-fill it.

DATA LOST and ordinary single-servant defeat are expected total-war progress.
Let the ORT result handler return to selection; never buy a revive, consume
command seals, Saint Quartz or Leyline Stones, reset the total war, or retry
an unavailable servant. Do not stop because a fixed number of sorties elapsed.

If a different finale (ORT Xibalba) or incompatible required party is shown,
report that concrete evidence instead of forcing this solo contract.
The regional chapter header "空想树海纪行 ORT·希巴尔巴" is also present on
the ordinary total-war map; that header alone is not finale evidence. Follow
the current mainline Next control there. Close a "编成条件" explanation with
its visible Close button before reporting or inspecting the party behind it.
