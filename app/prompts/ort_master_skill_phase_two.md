## ORT 二阶段／飞碟形态御主技能：计算场地扣血后的输出窗口

仅在 ORT 总体战 phase_two=true（form=flying）的 master_skill_plan 生效，覆盖普通刷图的保留习惯，不覆盖 schema、ready、封印或合法目标。每骑的总贡献取决于每次有效攻击与还能出手几次；DATA LOST 正常不等于应放弃可争取的额外回合。Galactica Supercell生效时，飞碟每回合结束有约1800～2200HP的伤害，并加剧宇宙线障碍；其中伤害可被有效回避／无敌阻挡，宇宙线障碍与最大HP减少不能视为一并被挡住。这项被动未在所有飞碟关卡数据中列出，不能仅凭外观断定一直存在，按当前状态／已见结算计入；未知时保留风险，不捏造已扣血，也不由出击数猜有无。第一形态后半的艾蕾支援（包括额外最大HP）不继承。先评估挡住普攻和回合末伤害后能否多出手，再分别判断三招，不能沿用第一形态的固定回合生存预期。

### 高伤害下先保住下一次攻击

飞碟普攻与暴击很重，攻略实战存在满万血仍首回合退场的情况。这是风险依据，不是本轮必定暴击或固定伤害。第1回合、满HP、敌方低充能都不代表安全；等倍／防御不利、敌方狂阶、己方低等级或缺少已生效保护时，优先考虑本回合有效无敌／回避，不等残血再救。即使防御有利，也要计入当前最大HP、敌方增攻／暴击状态与已见伤害，不能保证能挨一轮。无法读出精确伤害时不编数字，不以“尚未看到掉血”为保留防御的唯一理由。

“第2回合后再开回避”只是防御有利且能安全承受首轮时的攻略示例，不是固定时间表。若已有足够、已确认生效的保护，分开覆盖相邻敌方回合；回数制保护须检查剩余次数是否足以覆盖普攻与回合末追加伤害，不能看见一个图标就当成整轮安全。不把尚未执行的从者技能／未释放宝具当成现成防御，不为受击充NP而赌单骑死亡；用当前已确认保护与充能手段比较。

若本轮输出有充分依据能破当前条，优先兑现充能／增伤，不为必败的破条后脚本空放保护；“伤害很高”本身不等于必破，缺少把握时仍独立评估防御。若下一敌方回合是主要死亡风险，御主无敌能换来下一轮宝具或有效普攻就有价值，不因其不能永久抵消最大HP机制而放弃。已经确认无敌贯通、保护先被解除、或即使挡伤仍无法多出手时，才按具体原因放弃这项防御。

### 每回合先读当前证据，再分别判断三招

`ort_master_planning.servant_skills` 是本次截图的从者按钮读数；`catalog_cooldown` 只是资料库的总冷却，不是剩余 CD。只有 `cooldown_remaining` 配合 `cooldown_source` 或当前截图能用于回合计算。读不到就 unknown，绝不能把总 CD7/8/8 连续抄成第2、第3回合的剩余 CD。御主 catalog 自身的 cooldown_remaining 也不能当作从者剩余 CD。主图是当前御主面板，第二张图是同帧放大的单骑状态图标和从者技能按钮。

逐项查看三个御主技能，不得选完第一个就停止评估。reason 分别简述三招的“现在用/留到哪个具体窗口/无效或未知”，多招可以同回合一起选，max_skills 不是只能选一招。当前事实优先于历史笔记；旧战斗服的 Gandr/换人经验不能套到阿特拉斯院。

敌方充能低只表示宝具进度低，不表示普攻安全，不能据此断言“无致死威胁”；单骑满 HP 也不是必然能撑住下一轮。未知弱化不等于没有弱化：实际看放大的状态图标、从者技能/宝具是否被封印及当前文字。无法辨明可解除性时只保留净化，不把其他招一起跳过，也不为了三招都放而空放净化。

### 当前选用阿特拉斯院时

只在 master_code.code_id=mystic_code_40（或本轮 catalog 明确为阿特拉斯院三招）时应用以下配合。效果和数值仍以当前 catalog 为准，不能因上次选这套而忽略本次换装。当前这套没有治疗、充能、攻击强化或换人技能，不发明这些能力。单骑技能目标是本次实际在场、合法的字符串槽位，不默认永远为1。

- 欧西里斯之尘：一回合单体无敌。单骑普攻压力本身可构成用途；HP 已明显损失、下一次有效防御尚未就绪、继续受击会提前结束输出窗口时，应积极用它撑过一个敌方回合，不必等满充能或残血才考虑。若本回合已有可靠保护/控制足以覆盖且无其他威胁，保留至未保护的回合；若尚未执行的从者技能只是计划，不能当作已经保护。无敌不是对肃正防御：敌方无敌贯通、先解除强化或已知无视无敌的效果会使其无效。预计本次攻击就破条触发强制解除时，不把该无敌算作破条后保护。
- 伊西斯之雨：解除单体可解除弱化。优先恢复被技能/宝具封印、眩晕或魅惑压住的实际输出与防御能力；御主技能可用就不能因从者技能封印而全部 skip。宇宙线障碍、飞碟场地效果及当前已确认不可解除的灰框不能靠净化重置；不能清除敌方的无敌贯通，也不能恢复已被扣掉的 NP/星/最大HP。无当前可解除弱化时保留，不为预防未来异常空放。
- 梅杰德之眼：从者技能 CD 减2。优先让该单骑的有效回避/无敌/防御/控制、充能或输出技能在当前及剩余有效窗口内重开；当前 CD1～2 可立刻重用，CD3 可配合这回合保护争取下回合重用。不因不能立刻归零就一律拒绝，也不假定减 CD 后必活到下一回合。首回合三招全就绪不空放；剩余 CD 和用途未知时保留，不能凭角色记忆编造。它不减少另外两项御主技能的 CD，不直接解除封印。

三招的配合依据当前证据：可解除技能封印并有 CD1～2 防御时，可先净化再减 CD，让随后的从者阶段获得实际防御；关键技能还差一回合且本回合缺保护时，可用御主无敌桥接并减 CD。已有足够保护时避免把所有防御浪费在同一个敌方回合。不要输出从者技能 ID 或跨阶段执行序列；本计划只返回御主技能。

减 CD 必须比较最早重开回合，而非只看能否立刻归零：当前回合 T、剩余 c、减少 r 时，原最早 T+c，减后 T+max(0,c-r)。例如第2回合当前 CD4，减2后第4回合能重开，原来要第6回合；若第4回合仍有可用攻击窗口且该技能有收益，这已经是具体用途。不得仅以“减后仍大于0”否决，也不得在已知提前失效、技能不可用或无法活到该窗口时虚构收益。

无敌与减 CD 是可并用的互补方案，不是二选一：本回合用无敌撑住，减 CD 让下一回合防御/充能/输出重开，可以一起规划；不能以“HP危急，所以只无敌、不减CD”替代逐项判断。若无敌已冷却，净化和减 CD 仍须独立评估。先净化恢复行动，再执行依赖它的计划；没有当前可解除弱化则保留第二招，不试放探测。

### 飞碟场地与其他礼装

飞碟阶段的攻略建议约5回合内速攻，但不能仅因回合号推断当前已解除强化、扣光NP／星或技能封印。遇到解析／破条压制时以本帧图标和实际可用状态为准；不尝试净化不可解除机制、用普通无敌硬扛已确认的贯通，或把减 CD 当解除封印。已生效场地扣血和最大HP损失可能更早结束输出窗口，不保证活到任何固定回合。仍有合法有效行动就继续，不设回合／动作终止上限。

Galactica Supercell生效时，有效回避／无敌可阻挡飞碟回合末约1800～2200伤害，不要把它误写成无视无敌的固定扣血；宇宙线障碍加剧与最大HP损失另算。治疗不恢复已损失的最大HP，但在当前最大HP内有实际缺口、可帮助多出手时应及时用，不等濒死才治疗。

减 CD 的具体重开回合必须落在当前保护后仍可能存活且有收益的窗口内，远期重开必须有具体存活依据。先比较本回合／下回合能重开的防御、充能和输出技能；CD4减2仍需等待，不能默认飞碟单骑活到第4回合，再为这条远期路线保留眼前无敌。无敌能桥接且有具体重开收益时，两招仍可同回合并用；若当前证据表明本次攻击就是最后机会，优先本轮可兑现的充能／增伤，不能为了等待 CD 放弃可用宝具。未知存活结论应明确未知，不能照搬第一形态的艾蕾支援推算连发。

有用的本轮技能不能仅因希望留到“更危险的回合”而不用，留招应指出具体受保护窗口和下一用途。不要保证御主技能能在这次短战再次转好，也不改礼装／加队员／重启游戏来照抄攻略流程。

若所选礼装不同，按本轮三招实际效果规划：有效控制/防御换来攻击机会，净化恢复行动，充能/增伤兑现本轮伤害，回复只计实际能回复的 HP，单骑不使用换人。阿特拉斯院的技能名、数值和固定序号不能套给别的礼装。reason 简述本轮续回合/输出用途及留招的具体依据，不把未知 HP、冷却、控制命中或破条写成既成事实。

### 按飞碟具体机制修正三招用途

- 充能攻击 Lost Supernova／ロスト・スーパーノヴァ是先解除强化再攻击。无有效强化解除耐性／不可解除保护时，不能用普通可解除御主无敌承诺扛住充能攻击；这与回合末场地伤害可挡并不矛盾。优先比较当前可破条的充能／增伤、实际可命中的控制／减充能等方案，不虚构所选礼装有这些能力。敌方ＰＰチェイン／セブンエーテル可延迟转为每回合满充能，看到此状态就不能只按眼前低充能保留技能。
- 充能攻击后普通强化无效（3次／5回合）及NP增加效果量／NP获得下降，和不可解除的解析结束不是同一效果。幸存且当前确认可解除时，伊西斯之雨可先解除普通强化无效／相关弱化，恢复后续保护或充能的实际收益；有强化无效时不把刚选的无敌当作必定生效。仅NP获取受阻时不直接断言已蓄NP清零，也不把资料充能量当成当前必得NP。
- 第5回合敌方阶段／破条后解析是已查到的飞碟机制，应在窗口之前兑现技能与宝具，不是假设能无限拖延。是否已执行仍以当前状态为准；解析结束已确认时，其不可解除强化无效／封印及敌方贯通不能靠御主净化、普通无敌或减CD解决，不为等CD空耗当前攻击，也不按回合号主动停机。
- 有パラダイム・インフレーション强化复制时，御主／从者攻击强化均须考虑敌方增攻后的风险，但不因可能复制就一律禁用有效增伤；不假定充能、减CD、净化、无敌或全部宝具增益都同样被复制。有ダークマター・プランクトン回合末概率吸收时，现有攻防强化跨回合须重新核对，不能假定下回合仍有同样保护；本轮可兑现的收益仍计算。
- 有パラドックス・キャンセラー时，敌方回合末自净最多3个弱化并依成功数增攻，不把我方降攻／控制当成永续保护，也不放弃本轮已能发挥作用的弱化。敌方自净不等于需要我方净化；有エルンスト・ユニオン时，当前毒／灼伤／诅咒、防御下降与回复量下降才是评估己方净化／治疗的具体证据。
- 有エーテル・ドランカー时，每2回合概率吸收NP增加延迟宝具的风险；结合当前从者宝具作用、实际NP、充能技能及CD，优先把御主充能／减CD用于本轮可兑现的有效宝具，不编必扣数值或下轮一定触发。没有该被动时不以它否决其他有效路线。
