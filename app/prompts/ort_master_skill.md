## ORT 御主技能：争取额外输出回合

仅在 ORT 总体战 phase_two=false（第一形态）的 master_skill_plan 生效，覆盖普通刷图的保留习惯，不覆盖 schema、ready、封印或合法目标。每骑的总贡献取决于每次有效攻击与还能出手几次；DATA LOST 正常不等于应放弃可争取的额外回合。不要把“第5回合解析”当作此前不值得防御、清弱化或减 CD 的理由；也不承诺必定撑过解析。

### 每回合先读当前证据，再分别判断三招

`ort_master_planning.servant_skills` 是本次截图的从者按钮读数；`catalog_cooldown` 只是资料库的总冷却，不是剩余 CD。只有 `cooldown_remaining` 配合 `cooldown_source` 或当前截图能用于回合计算。读不到就 unknown，绝不能把总 CD7/8/8 连续抄成第2、第3回合的剩余 CD。御主 catalog 自身的 cooldown_remaining 也不能当作从者剩余 CD。主图是当前御主面板，第二张图是同帧放大的单骑状态图标和从者技能按钮。

逐项查看三个御主技能，不得选完第一个就停止评估。reason 分别简述三招的“现在用/留到哪个具体窗口/无效或未知”，多招可以同回合一起选，max_skills 不是只能选一招。当前事实优先于历史笔记；旧战斗服的 Gandr/换人经验不能套到阿特拉斯院。

敌方充能低只表示宝具进度低，不表示普攻安全，不能据此断言“无致死威胁”；单骑满 HP 也不是必然能撑住下一轮。未知弱化不等于没有弱化：实际看放大的状态图标、从者技能/宝具是否被封印及当前文字。无法辨明可解除性时只保留净化，不把其他招一起跳过，也不为了三招都放而空放净化。

### 高伤害下的防御时机

“第2回合后再开回避”只是防御有利且能安全承受首轮时的攻略示例，不是固定时间表。等倍／防御不利、敌方狂阶、己方低等级或当前最大HP偏低、敌方已见增攻／暴击威胁时，第1回合也应积极使用有效保护，不等残血或满充能。防御有利不保证安全，缺伤害读数时不编数字，也不以尚未掉血证明可以硬吃。第一形态后半的额外最大HP仅在本帧确认后计入，不能在全阶段默认拥有。

防御目标是多获得一次宝具或有效攻击；不为受击充NP而赌单骑死亡。已确认生效的保护足够时错开覆盖相邻回合；回数制保护按剩余次数判断，未执行的从者防御／宝具不当成已经保护。当前输出有充分依据能破条时优先兑现充能／增伤，不为破条后强制退场空放保护；“伤害很高”本身不是必破依据。无敌贯通或先解除等使保护无效时说明具体原因，不把宇宙线障碍无法解除误当成所有防御都无价值。

减 CD 先考虑本回合／下回合能重开的防御、充能或输出；远期重开必须有具体存活依据，不能为等CD而保留眼前有用的无敌。若当前礼装有治疗，在当前最大HP内有实际可回复缺口且能帮助多出手时及时用，不等濒死；御主技能通常只需考虑本次短战的有效使用，不幻想整套再次转好。

### 当前选用阿特拉斯院时

只在 master_code.code_id=mystic_code_40（或本轮 catalog 明确为阿特拉斯院三招）时应用以下配合。效果和数值仍以当前 catalog 为准，不能因上次选这套而忽略本次换装。当前这套没有治疗、充能、攻击强化或换人技能，不发明这些能力。单骑技能目标是本次实际在场、合法的字符串槽位，不默认永远为1。

- 欧西里斯之尘：一回合单体无敌。单骑普攻压力本身可构成用途；HP 已明显损失、下一次有效防御尚未就绪、继续受击会提前结束输出窗口时，应积极用它撑过一个敌方回合，不必等满充能或残血才考虑。若本回合已有可靠保护/控制足以覆盖且无其他威胁，保留至未保护的回合；若尚未执行的从者技能只是计划，不能当作已经保护。无敌不是对肃正防御：敌方无敌贯通、先解除强化或已知无视无敌的效果会使其无效。预计本次攻击就破条触发强制解除时，不把该无敌算作破条后保护。
- 伊西斯之雨：解除单体可解除弱化。优先恢复被技能/宝具封印、眩晕或魅惑压住的实际输出与防御能力；御主技能可用就不能因从者技能封印而全部 skip。灰框解析完成、宇宙线障碍等不可解除的机制不能靠净化重置；不能清除敌方的无敌贯通，也不能恢复已被扣掉的 NP/星/最大HP。无当前可解除弱化时保留，不为预防未来异常空放。
- 梅杰德之眼：从者技能 CD 减2。优先让该单骑的有效回避/无敌/防御/控制、充能或输出技能在当前及剩余有效窗口内重开；当前 CD1～2 可立刻重用，CD3 可配合这回合保护争取下回合重用。不因不能立刻归零就一律拒绝，也不假定减 CD 后必活到下一回合。首回合三招全就绪不空放；剩余 CD 和用途未知时保留，不能凭角色记忆编造。它不减少另外两项御主技能的 CD，不直接解除封印。

三招的配合依据当前证据：可解除技能封印并有 CD1～2 防御时，可先净化再减 CD，让随后的从者阶段获得实际防御；关键技能还差一回合且本回合缺保护时，可用御主无敌桥接并减 CD。已有足够保护时避免把所有防御浪费在同一个敌方回合。不要输出从者技能 ID 或跨阶段执行序列；本计划只返回御主技能。

减 CD 必须比较最早重开回合，而非只看能否立刻归零：当前回合 T、剩余 c、减少 r 时，原最早 T+c，减后 T+max(0,c-r)。例如第2回合当前 CD4，减2后第4回合能重开，原来要第6回合；若第4回合仍有可用攻击窗口且该技能有收益，这已经是具体用途。不得仅以“减后仍大于0”否决，也不得在已知提前失效、技能不可用或无法活到该窗口时虚构收益。

无敌与减 CD 是可并用的互补方案，不是二选一：本回合用无敌撑住，减 CD 让下一回合防御/充能/输出重开，可以一起规划；不能以“HP危急，所以只无敌、不减CD”替代逐项判断。若无敌已冷却，净化和减 CD 仍须独立评估。先净化恢复行动，再执行依赖它的计划；没有当前可解除弱化则保留第二招，不试放探测。

### 解析与其他礼装

第5回合行动前或破条后会强制解除主动强化、扣 NP/星并施加解析，ORT 获得无敌贯通。解析后的具体灰框和当前可用状态优先，不尝试净化不可解除机制、用普通无敌硬扛贯通，或把减 CD 当作解除封印；仍有合法有效行动就继续，不设置回合/动作终止上限。解析前的有效攻击窗口应尽量兑现，不把所有技能留给已知会失效的时机。

若所选礼装不同，按本轮三招实际效果规划：有效控制/防御换来攻击机会，净化恢复行动，充能/增伤兑现本轮伤害，回复只计实际能回复的 HP，单骑不使用换人。阿特拉斯院的技能名、数值和固定序号不能套给别的礼装。reason 简述本轮续回合/输出用途及留招的具体依据，不把未知 HP、冷却、控制命中或破条写成既成事实。

### 最终输出仍是本任务 JSON

不要只返回 {} 或策略说明。有合法有用技能时 action=master_skill_plan，arguments.master_skills 为实际 catalog 中的条目；没有收益时 action=skip，arguments={}。两者仍须给 confidence 和 reason，不输出字段之外的计划；下例 ID/目标只是格式，不是本轮授权。
