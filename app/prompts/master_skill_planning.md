## 御主技能的整场收益规划

本节仅用于 master_skill_plan，完整/精简提示词执行同一策略。以 master_code.code_id、等级及 master_skill_catalog 的实际效果为准，切换礼装后不沿用旧套装技能；不靠套装名字补造充能、治疗、无敌或换人能力。

所有运行模式均提供 servant_knowledge 与 servant_master_planning：按 owner_slot 关联当前在场从者的三项技能（效果、目标、持续时间、usage_guidance、资料总CD和当前剩余CD）、noble_phantasm（宝具效果与副作用）、NP充能和HP。先读这些信息，再判断御主充能是否补足宝具缺口、增伤是否作用于本轮输出、防御是否与从者保护重复、净化是否恢复关键能力、减CD能重开哪一招。宝具充能达到100不代表未被封印；效果未知不能当成无效果，读不到的状态保留unknown，不凭角色记忆补造。

主图是当前御主面板与完整战场，其后的放大图由 image_roles 标注 owner_slot 和裁剪区域，覆盖该槽位状态图标、HP/NP与三枚技能按钮；相邻槽位可能重叠，不能认错归属。servant_master_planning 的 cooldown_remaining 配合 cooldown_source 才是当前CD，catalog_cooldown只是资料值。当前按钮ready探针是辅助证据，无法判定或与画面冲突时看本轮图，不因探针置信度拒绝截图已确认的状态。从者技能尚未执行、宝具尚未释放，不能把它们的保护／充能当作已经生效，也不能在本阶段输出从者技能或宝具动作。

每次逐项检查三招，再选所有当前有明确贡献且无更大代价的合法技能。不要把“最少点几次”“缺精确伤害”“普通攻击也能打”当作一律 skip 的理由。整场规划是有证据的时机比较，不要求证明最优、必杀或必定活到某回合。
max_skills 是本次计划的条目上限，不是游戏“每回合只能用一个御主技能”的规则；允许范围内可按依赖连续使用多招。效果数值与冷却按本次礼装等级、catalog 和当前剩余 CD 读取，不能把满级值或初始冷却当现值。

- 充能/增伤：看实际受益者的 NP 缺口、已知宝具类型、已有增益和当前输出机会。充能可启用本回合宝具或推进明确后续用途；满 NP 不否决复合增益。通用长效收益可早用，一回合爆发贴当前有效攻击；不为凑次数浪费在已知伤害无效阶段。不虚构 Attack 前五张卡或尚未执行的从者充能。
- 防御/回复/控制：目标是增加有效出手次数，普攻、连续攻击、持续伤害和异常也会减少出手机会，不只在敌方宝具满槽时才考虑。独苗或关键输出已面临可信的普攻压力且没有有效保护时，无敌/回避可直接有价值，不要求精算致死。确认敌方贯通/必中、强化解除、伤害类型和已有保护；确定有效的另一重保护或控制已足够时分开使用，争取覆盖不同敌方回合。概率控制不等于必然成功，不能把后续从者技能当作已经命中。
- 净化：可解除的眩晕/魅惑、技能/宝具封印、妨碍关键输出或生存的弱化均可成为用途。御主未封印时，从者不能行动不妨碍给其合法净化；这与禁止把无法行动者换下场是两回事。净化不是弱化无效，不会移除敌方 buff、灰框不可解除状态、DATA LOST 或复活退场者；负面标签不清楚时只不计该效果。
- 减冷却：读受益者当前技能剩余 CD 与已知效果，不是看御主技能自己的 CD。当前 CD 1～2 的有用技能可立即重开，CD 更长但能在预计剩余有效回合内提前重开也有价值，例如当前 CD3 减2后下回合可用。原本全就绪时保留；不能为未来从者施法预支收益。本阶段先于从者技能，不能规划“从者先放、再减 CD”或声称减少御主自己的冷却。减 CD 不解除封印，也不延长 buff 持续时间；无读数时不用技能的满级总 CD 冒充剩余 CD。
- 换人/洗牌/出星等：必须有当前合法人员、效果、任务目标或已知卡面用途；不能凭空造替补、选卡或跨阶段操作。换人能否执行仍服从本次状态限制。单骑无后排时没有换人价值。

主线按当前波次、剧情限制和可见血条比较眼前与后续收益；自由关卡/无限刷按实际清场阈值、NP 衔接和可靠周转比较，不为了少一次技能造成多一回合。不能假定每关三面、下一面固定敌人、御主技能下回合自动回满。冷却结束的技能即使 used=true 仍可再次使用。

先解决阻止后续技能生效的可解除弱化，再执行依赖它的增益；其他技能按真实依赖排序。CD2 减2归零是在本回合随后的从者技能阶段即可使用，不是等下回合；CD3 减2剩1才需要等回合推进。每个条目只复制 catalog ID 和合法目标，遵守 max_skills 与 ready，不强行三招全开。reason 简写实际收益和保留理由；skip 时指出当前三招为何没有用途，不能用“无威胁/等待更佳时机”替代事实。未知信息仅缩小相应方案，不跳过其余有用技能。
